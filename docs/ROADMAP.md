# 后续开发与验收

当前完成的是使用合成样本验证的研究首版。开发优先级继续以公募和私募为主，ETF/海外模型保留明确扩展位置。

|优先级|下一项|可验收结果|
|---|---|---|
|P0|真实公募小样本对账|至少股、债各两只，单位/复权/分红一致；真实节假日；采集快照可追溯|
|P0|真实私募导入验收|月/周净值、真实披露日期、开放期、锁定期、费率完整；用人工账本逐笔核对|
|P0（已实现软件路径）|条款和分类版本|管理人、策略、开放日与费用按有效期和获知日查询；订单/Lot冻结版本并导出复核证据；真实合同样本仍待验收|
|P1|更完整的基金会计|红利再投、登记日权益、拆分、清算、FOF层费用、份额精度与尾差，有逐笔对账测试|
|P1|私募流动性压力|巨额赎回、部分确认、暂停赎回、动态到账延迟；最差现金缺口可解释|
|P1|研究稳健性|固定样本外区间、滚动窗口与成本敏感性；加入退出基金，量化幸存者/回填偏差|
|P1|平台只读接入|导入版本化快照，校验重复运行与资金分项；真实持仓导入后再启用持续监控|
|P2|ETF与海外|场内收盘/成交价格、复权、滑点、交易单位、汇率、跨市场日历；独立模型测试|
|P2|更多模型|接入Riskfolio-Lib、因子风险预算或CVaR；与已有基线同数据、同费用、同执行口径比较|

研究上应先确保数据与申赎账本可信，再评价配置方法。首版合成样本的收益高低不用于决定实盘策略。
